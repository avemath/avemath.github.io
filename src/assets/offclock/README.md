Photos for the pins of the AVE-26 datasheet on the About page. Name each file in the matching pin's
`photo` field in `src/data/about.json` as a path under `src/assets/` (for example
`offclock/canoe.jpg`), and give it an `alt`. JPEG or WebP, at least 1000px on the long side; the
build resizes them. Each shows as a square Polaroid print, so square or near-square crops work best.
